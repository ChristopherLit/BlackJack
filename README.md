# 🃏 Blackjack Game

A fun and simple Blackjack game built with **React** and **Vite**. Play against the dealer and try your luck to hit 21 without going bust!

![Blackjack Demo](./demo/blackjack-demo.gif)

---

## 🚀 Features

- Classic Blackjack rules
- Play against the dealer
- Responsive UI
- Fast performance with Vite

---

## 🛠️ Tech Stack

- React
- Vite
- TailwindCSS
- JavaScript
